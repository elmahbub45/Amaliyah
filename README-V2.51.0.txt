AMALIYAH V2.51.0 — QUR'AN OFFLINE

Arah offline final:
- Shell aplikasi tetap bisa dibuka tanpa internet setelah pernah dibuka online.
- Favorit, bookmark, riwayat, progres, dan data lokal tetap tampil saat offline.
- PDF tetap online-only dan tidak disimpan ke Cache Storage / IndexedDB.
- Cache PDF eksperimen V2.50.x dibersihkan otomatis.
- Saat PDF ditekan dalam kondisi offline, aplikasi memberi pesan ramah bahwa PDF membutuhkan internet.
- Al-Qur'an dapat diunduh 604 halaman untuk dibaca offline.
- Unduhan Qur'an bisa dilanjutkan jika terhenti, menampilkan progres, dan bisa dihapus dari Pengaturan.
- Halaman Qur'an yang pernah dibaca tetap masuk cache yang sama sehingga ikut dihitung dalam progres offline.

Catatan:
Unduh Al-Qur'an dilakukan saat aplikasi terbuka dan internet aktif. Jangan menutup aplikasi sebelum unduhan selesai jika ingin seluruh 604 halaman langsung tersedia.
