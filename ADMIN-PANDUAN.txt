PENTING TENTANG PDF / R2
PDF Amaliyah sekarang PRIVATE di Cloudflare R2.

books.json tetap memakai path virtual seperti:
assets/pdf-v2/maulid/al-azab/nama-file.pdf

Admin akan menampilkan R2 key:
maulid/al-azab/nama-file.pdf

Untuk PDF BARU:
1. Tentukan path virtual pada Admin.
2. Perhatikan "R2 key" yang ditampilkan.
3. Upload PDF ke bucket R2 dengan key/folder yang SAMA.
4. Download books.json dari Admin.
5. Replace books.json di GitHub dan commit.

JANGAN upload PDF rahasia kembali ke GitHub.

ALUR AMAN SETIAP EDIT
1. Buka Admin.
2. Edit data.
3. Pastikan Error = 0.
4. Klik Preview & Download.
5. Download books.json.
6. Replace books.json di GitHub.
7. Commit.
8. Tes satu bacaan yang diedit.

CATATAN ID
Jangan mengganti ID bacaan/bagian lama.
ID dipakai untuk progres, bookmark, favorit, dan riwayat pengguna.

SHORTCUT

Ctrl+E = Preview/validasi export

BACKUP
Backup tersimpan lokal di browser/perangkat yang dipakai membuka Admin.
Backup bukan cloud backup. Untuk backup permanen, download salah satu backup
dari menu Backup.
