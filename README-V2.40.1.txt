AMALIYAH V2.40.1 — SEARCHABLE SVG CATEGORY ICONS

Pembaruan:
- Pemilih ikon kategori di Admin diperluas menjadi 35 ikon SVG.
- Ditambahkan ikon Masjid, Ka'bah, Tasbih, Kiblat, Jamaah, Naskah,
  Pengeras Suara, Waktu, Kalender, Pelita, dan ikon umum lainnya.
- Pencarian ikon berdasarkan nama dan kata kunci.
- Ikon pilihan tetap disimpan sebagai kode ringkas di categoryIcons books.json.
- Ikon baru tampil konsisten di Beranda, Semua Kategori, Bacaan Terakhir,
  Favorit, dan halaman daftar bacaan.
- Cache Service Worker diperbarui agar icon-library.js langsung ikut dimuat.

Cara memakai:
1. Buka Admin Koleksi.
2. Klik folder kategori di panel kiri.
3. Pada panel kanan, cari atau pilih ikon kategori.
4. Klik Preview & Download, lalu unggah books.json terbaru ke GitHub.

Catatan:
- Perubahan ikon tidak mengubah ID, file PDF, progres baca, atau bookmark.
- Semua SVG tersimpan lokal; aplikasi tidak bergantung pada server ikon luar.
